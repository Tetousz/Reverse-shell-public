Setup Guide

Follow these steps to install, configure, and run the Reverse Shell Controller.

1. Prerequisites

  • Python 3.10 or newer.
  • pip (Python package manager).
  • Flask (required for the web dashboard).
  • Ngrok (included as a binary in the repository root).

Install Flask using your system's package manager:

# On Arch Linux
sudo pacman -S python-flask

# Or using pip
pip install flask

2. Installation

Clone the repository and install the required dependencies:

git clone https://github.com/Tetousz/Reverse-shell-public.git
cd Reverse-shell-public
pip install -r requirements.txt

Verify your Python installation:

python3 --version

3. Ngrok Configuration (Optional)

Ngrok is required if you want to connect to clients on different networks. If you only plan to test locally, you can skip this.

Authenticate Ngrok using your token:

./ngrok config add-authtoken <YOUR_TOKEN>

Start the TCP tunnel on port 4444:

./ngrok tcp 4444

Important: Keep this Ngrok process running in the background. The exporter detects the active tunnel and bakes the public URL into the payload.

4. Starting the Server

RSC provides two dashboard interfaces. The Web Dashboard is recommended.

Web Dashboard:

python3 -m web.main

The browser should open automatically to http://127.0.0.1:8000.

Tk Dashboard (Fallback):

python3 -m dashboard.main

5. Exporting a Payload

  1. In the Web Dashboard, click Start Server.
  2. Click Export Payload.
  3. Select your desired format (e.g., py).

This generates a .zip file in the builds/ folder. The archive contains the payload script and the required core/ dependencies.

6. Testing Local Connection

Extract the archive to a temporary directory and run it:

mkdir -p /tmp/test/
unzip builds/payload_py.zip -d /tmp/test/
cd /tmp/test/
python3 payload_py.py

You should see a new session appear in the dashboard.

7. Testing Remote Connection

If Ngrok was running when you exported the payload, you can transfer the unzipped folder to a different machine. Run the payload, and it will automatically connect back via the baked-in Ngrok URL.

8. Troubleshooting

Port 4444 is already in use

Find and stop the conflicting process:

sudo lsof -i :4444
Ngrok forwarding address changed

Free Ngrok addresses change when restarted. You must restart the server and export a new payload.

ModuleNotFoundError: No module named 'flask'

Flask is missing from your environment. Run: pip install flask.
