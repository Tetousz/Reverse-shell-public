Architecture

The project is split into four primary modules:

  • Core: Shared utilities (HMAC auth, persistent state, Ngrok detection).
  • Web: Flask + SSE dashboard running on localhost:8000.
  • Exporter: Packages Python clients into portable ZIPs (`.py`, `.sh`, `.bat`, `.js`, `.exe`).
  • Modules: The TCP server handling connections and command dispatch.
